A program that draws one 1024x1024 newspaper front page summing up Wednesday 25 November 2026 world news: two tankers ablaze in the Strait of Hormuz, Houthi strikes on Saudi Arabia, Russian strikes on Ukraine, the Huawei verdict, and a UTC timeline of the day. Every story on the page is dated 25 November 2026. Python 3 standard library only, no network, deterministic.

## Run it

```sh
python3 main.py
```

The program writes exactly one file, `entry.png`, to `$MAKEFUN_OUTPUT_DIR` (default `/output/entry.png`).
